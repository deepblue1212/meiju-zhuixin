# 美剧追新

<img src="ICON.PNG" alt="美剧追新图标" width="80" height="80">

**在飞牛 NAS 上发现美剧、搜索资源、添加下载任务，并匹配中文字幕。**

美剧追新是一款 fnOS 桌面应用，原名「媒体链接助手」。从豆瓣美剧列表出发，识别中英文片名，筛选想要的资源，再交给飞牛自带的下载应用处理。应用内部标识继续使用 `media_link_helper`，便于已有用户覆盖升级。

当前公开版本：**1.9.2**。

安装包 SHA-256：

```text
a9c4d194ac9134758458f3bca404ae1f5e63085a95b67fe0ca29eeb1ddce88c6
```

1. 在飞牛应用中心安装 Python 3.12（应用标识为 `python312`）；安装包已声明该依赖。
2. 下载上面的 `.fpk` 文件，在应用中心使用「手动安装」。
3. 安装完成后，从**飞牛桌面**打开「美剧追新」。
4. 在飞牛下载应用中设置默认存储目录，确保目录可用且可写。
5. 如需自动查找和下载字幕，打开「字幕设置」，填写 ASSRT Token，也可配置 OpenSubtitles API key 作为备源。

包内声明最低系统版本为 **fnOS 1.2.0401**。飞牛下载联动需要当前桌面提供相应接口，并且登录账号具有操作权限；本版本的应用入口限管理员访问。

已有版本可用同一应用标识覆盖升级。升级前请保留现有安装包及应用配置备份。

## 主要功能

| 功能 | 具体说明 |
| --- | --- |
| 美剧发现 | 首页显示豆瓣接口返回的美剧名称和评分，支持手动刷新，最多读取 60 条；点击剧名进入资源搜索。 |
| 中英文片名识别 | 输入中文片名后展示可能对应的英文作品，选择后搜索；支持豆瓣、Wikidata 和内置片名别名。 |
| 资源搜索 | 优先查询 APIBay，没有结果或请求失败时顺序尝试备用索引，最多显示 50 条资源。 |
| 版本信息展示 | 识别发布名中的季、集、年份、分辨率、来源格式和视频编码，辅助区分不同版本。 |
| 筛选与排序 | 按季、集、分辨率和编码筛选；按做种数、体积、发布日期或季集排序，也可将筛选条件加入新搜索。 |
| 下载到飞牛 | 支持单条下载、勾选多条批量添加和手动粘贴磁力链接；添加前显示飞牛当前默认下载目录，并可打开飞牛下载查看进度。 |
| 复制磁力链接 | 可复制单条或批量复制选中的链接，方便在其他下载工具中使用。 |
| 中文字幕匹配 | ASSRT 为主源，OpenSubtitles 为备源；结合片名、年份、季集和发布版本筛选候选字幕。 |
| 自动匹配并下载 | 唯一候选满足完整发布名匹配，且只含一个合适字幕文件时，可直接发起下载；存在歧义或多个文件时需要选择。 |
| 字幕同名保存 | 填入实际视频文件名，或选择本地视频取得文件名，即可按视频名称保存字幕；也支持已有字幕文件同名另存。 |
| 跳过字幕查找 | 可标记已有中文字幕的资源；该选择保存在当前浏览器中。 |
| 窄窗口布局 | 紧凑导航与列表布局，窄窗口会自动换行。 |

## 使用流程

### 找剧并下载

1. 在首页浏览美剧列表，或进入搜索页输入片名。
2. 中文片名出现多个英文候选时，先选择正确的作品。
3. 根据季集、清晰度、编码和资源信息选择版本。
4. 点击「下载到飞牛」，或勾选多条后点击「下载选中到飞牛」。
5. 核对确认框中的存储目录，确认添加后，在飞牛下载中查看实际下载状态。

每次打开下载确认框都会重新读取飞牛下载的默认目录。更改默认目录后，关闭已经打开的确认框，再重新打开即可刷新显示。已有下载任务的位置由飞牛下载应用管理。

如果添加任务时提示响应超时或结果无法确认，先检查飞牛下载列表，避免重复提交。

### 匹配中文字幕

1. 在「字幕设置」保存 ASSRT Token；需要备源时再填写 OpenSubtitles API key。
2. 打开某条资源的「中文字幕」面板，查看自动查找的候选。
3. 可点击「自动匹配并下载」，或手动选择候选、语言和对应文件。
4. 如需与视频同名，先填写实际下载的视频文件名；留空时保留处理后的字幕原名。
5. 将浏览器下载的字幕放到 NAS 视频同一目录，播放确认时间轴是否同步。

支持直接处理 **SRT、ASS、SSA、VTT**。ZIP、RAR、7Z、图片字幕等需要到来源网站下载并自行处理。SubHD 提供网站入口。

字幕服务密钥保存在 NAS 应用配置目录中，不会回显到设置页面。设置显示「已配置」仅表示已经保存，实际可用性在调用服务时确认。空输入保留原值，勾选对应清除选项才会删除已保存的密钥。

## 当前版本的范围与限制

- 当前流程由用户主动浏览、搜索和添加任务触发；尚未实现剧集订阅、定时追更、自动下载新集或媒体库自动整理。
- **字幕保存到浏览器下载目录**，不会自动写入 NAS 视频旁，也没有下载完成后的后台补字幕流程。
- 标题里的「中字」等标记只是发布名提示，应用不会读取视频检查内嵌字幕轨，也不会转换字幕的简繁体内容。
- 作品列表、资源索引及字幕结果依赖第三方服务的网络状态、数据、密钥权限和配额；首页顺序采用豆瓣接口返回顺序。
- **1.9.2 已知问题：**全部资源搜索源请求失败时，前端仍可能显示「没有找到结果」，未充分区分来源故障与确实没有资源。
- 本仓库不包含真实字幕密钥、NAS 配置、视频文件或用户下载记录。

## 源码结构

```text
app/
  server.py                 HTTP 服务、片名识别、作品发现和资源搜索
  subtitle_providers.py     ASSRT / OpenSubtitles 字幕服务
  subtitles.py              SubHD 查询解析与字幕匹配辅助逻辑
  public/                   页面、样式、飞牛桌面联动及字幕交互
  ui/                       飞牛桌面入口和图标
cmd/                        安装、启停、升级和卸载脚本
config/                     应用权限与资源配置
manifest                    fnOS 安装包元数据
tests/                      字幕、HTTP 接口、前端和桌面联动测试
dist/                       原版 1.9.2 FPK 及 SHA-256 校验文件
```

`app/`、`cmd/`、`config/`、`manifest` 和图标来自发布的 1.9.2 FPK；本次公开整理未修改安装包内的应用逻辑。

## 构建

准备适合本机系统的飞牛 `fnpack` 工具，在仓库根目录执行：

```bash
chmod +x cmd/*
fnpack build --directory .
```

安装包只应包含应用运行文件。不要把实际令牌、字幕设置、日志或缓存加入构建目录。`dist/` 中保留的是原始发布包；重新构建时归档时间等信息可能变化，因此文件哈希不一定与原包相同。
